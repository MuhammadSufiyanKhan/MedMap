# Blockers

Things only the repository owner can do. The build does not wait for them.

| --- | -------------------------------------------------------------------- | ------------------------------ | ------ |
| 1   | Choose a repository licence                                          | Adding `LICENSE`, public reuse | open   |
| 2   | Provide a real interaction dataset and confirm its licence and terms | Any production deploy          | open   |
| 3   | Legal review of the medical disclaimer and fixed safety wording      | Any production deploy          | open   |
| 4   | Create Vercel, Render and Atlas resources and add secrets            | Staging and production deploys | open   |
| 5   | Supply a label-extraction provider key (optional)                    | Photo extraction on deploys    | open   |
