# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Use GitHub's private reporting: open the repository's **Security** tab and choose
**Report a vulnerability**. Include what you found, how to reproduce it and the impact you
expect. Do not include real health data.

You should get a first answer within 7 days.

## Scope

MedMap handles sensitive health information. Reports about authentication, authorisation
between profiles, data export and deletion, upload handling and logging of personal data
are especially welcome.

How the application is secured is described in [docs/SECURITY.md](docs/SECURITY.md).
